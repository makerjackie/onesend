# OneSend 1.5.3

## 中文

- 桌面端信息密度与壳层重做：NavigationRail 展示品牌，宽屏首页并入最近传输，发送/接收使用双栏 workbench。
- Flutter 与官网视觉 token 对齐（ink / lime / paper / line），卡片改为浅面 + 细线描边。
- 传输模式主路径统一为「二维码 / 彩色视觉码」；可靠 / 快速 / Turbo 作为设置里的高级档位。
- 宽屏设置与文件操作改用 Dialog，手机仍用 BottomSheet。
- macOS 默认窗口改为 1100×720。

## English

- Desktop shell and density pass: branded NavigationRail, home history on wide layouts, two-column send/receive workbench.
- Flutter brand tokens aligned with the website (ink / lime / paper / line) and bordered surfaces.
- Primary transfer modes are QR vs color code; Reliable / Fast / Turbo stay advanced QR profiles in Settings.
- Desktop pickers use dialogs; phones keep bottom sheets.
- macOS default window size is now 1100×720.
