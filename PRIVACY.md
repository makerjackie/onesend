# OneSend Privacy Notice

Last updated: 2026-08-01

OneSend is designed for local, offline-first file transfer over animated QR codes.

## Data handled on your devices

- The file you choose is read locally so it can be encoded into QR frames.
- The receiving camera is used locally to scan QR frames.
- A received file is written to the local OneSend/Received folder.
- A small transfer history (file name, size, direction, status, time and local path) is stored on the device for the recent-transfers screen.

## Data we do not collect

OneSend does not include an account system, analytics service, advertising SDK, network transfer service, cloud storage, or remote file upload. OneSend does not send file contents or camera frames to us.

## Permissions

Camera permission is required only when receiving a file. File access or document-picker permission is used when you select a file or save a received file, subject to the platform's permission model.

## Contact

For privacy questions, open an issue in the project's GitHub repository.
